# `version` 命令帮助文档

```text
CARGO-VERSION(1)

名称
       cargo-version — 显示版本信息

概要
       cargo version [选项]

描述
       显示 Cargo 的版本。

选项
       -v, --verbose
           显示额外的版本信息。

示例
       1. 显示版本：

              cargo version

       2. 版本也可以通过标志获取：

              cargo --version
              cargo -V

       3. 显示额外的版本信息：

              cargo -Vv

另请参阅
       cargo(1)
```
