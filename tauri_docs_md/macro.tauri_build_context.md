Expand description

Include a [`Context`][5] that was generated by [`tauri-build`][6] inside your build script.

You should either use [`tauri-build`][6] and this macro to include the compile time generated code, or [`generate_context!`][7]. Do not use both at the same time, as they generate the same code and will cause excess computations that will be discarded.
